## Troubleshooting

### 1. `fatal: remote origin already exists`
- **Cause**: Trying to add remote `origin` when it is already configured.
- **Solution**: Inspect current remotes with `git remote -v` or update the URL using `git remote set-url origin <URL>`.

### 2. `Permission denied (publickey)` when pushing to GitHub
- **Cause**: SSH keys are not configured with your GitHub account.
- **Solution**: Set up an SSH key in GitHub settings or use HTTPS remote URL:
  ```bash
  git remote set-url origin https://github.com/ftabassum0502-stack/Faiza-Tabassum.git
  ```
